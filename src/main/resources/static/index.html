Como jogar

  • Use as setas ou WASD para movimentar o rato.
  • Encoste na comida para coletá-la.
  • Volte ao bueiro para entregar a comida.
  • No bueiro, você fica protegido.
  • Fuja do gato e da pessoa com a vassoura!
  • Segure E perto de uma caixa para se esconder por até 3 segundos.
  • Depois de sair, espere 6 segundos para se esconder novamente.
  • Desvie dos cones: eles bloqueiam sua passagem!
